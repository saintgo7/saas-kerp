## 1. Docker 설정

### 1.1 Go API Server Dockerfile

```dockerfile
# deployments/docker/api-server/Dockerfile
FROM golang:1.22-alpine AS builder

WORKDIR /app

# 의존성 캐시
COPY go.mod go.sum ./
RUN go mod download

# 소스 복사 및 빌드
COPY . .
RUN CGO_ENABLED=0 GOOS=linux go build -o /bin/api ./cmd/api

# 실행 이미지
FROM alpine:3.19

RUN apk --no-cache add ca-certificates tzdata
ENV TZ=Asia/Seoul

COPY --from=builder /bin/api /bin/api

EXPOSE 8080

CMD ["/bin/api"]
```

### 1.2 Python Tax Scraper Dockerfile

```dockerfile
# python-services/tax-scraper/Dockerfile
FROM python:3.11-slim

WORKDIR /app

# 시스템 패키지

    chromium \
    chromium-driver \
    fonts-nanum \

ENV PYTHONPATH=/app
ENV PLAYWRIGHT_BROWSERS_PATH=/root/.cache/ms-playwright

```

### 1.4 Docker Compose (개발환경)

      - "5432:5432"

  api-server:
    build:
      context: .
      dockerfile: deployments/docker/api-server/Dockerfile
    ports:
      - "8080:8080"

      - "50051:50051"

## 4. abada-65 배포 (https://kerp.abada.co.kr)

Traefik 없이 Cloudflare 터널(abada-srv65) → `127.0.0.1:10252`(web nginx) 한 호스트로 서비스한다.
web nginx 가 `/api/`·`/health*` 를 api 로 넘긴다(`deployments/docker/nginx/nginx-abada65.conf`).
설정 차이는 `deployments/docker/docker-compose.abada65.yml` 하나에 있다(포트 10252/10253 루프백, Traefik·모니터링·worker·Python 서비스는 `disabled` 프로필).

- 위치: `/data/abada-co-kr/kerp-abada-co-kr/kerp.abada.co.kr/` (이 저장소 clone)
- `.env`: `deployments/docker/.env` (600, 서버에서 생성). 베이스 compose 의 `${VAR:?}` 가드 때문에 꺼진 서비스 것까지 9개가 모두 있어야 한다:
  `DB_PASSWORD JWT_SECRET KERP_HR_FIELD_KEY MINIO_ROOT_USER MINIO_PASSWORD MEILI_KEY ARIA_ENCRYPTION_KEY GRAFANA_USER GRAFANA_PASSWORD`, 그리고 이미지 태그 `KERP_IMAGE_TAG`(커밋 SHA).
- 첫 배포 순서 (`cd deployments/docker`, `C="docker-compose -p kerp -f docker-compose.yml -f docker-compose.abada65.yml"`):
  1. `$C config -q` → `$C build api web`
  2. `$C up -d postgres redis nats`
  3. `$C run --rm --no-deps --entrypoint /app/migrate api up` → `version 25`, dirty=false
  4. 시드 `db/seed/001`~`003` 을 `psql -v ON_ERROR_STOP=1 --single-transaction` 으로 적용. `004_demo_company` 는 운영에 넣지 않는다.
     표준 계정과목 함수 `create_standard_accounts()` 는 시드가 아니라 마이그레이션 `000024` 가 정의한다. 회원가입이 회사를 만들 때 같은 트랜잭션에서 109개 계정을 만들고, 000024 는 계정이 하나도 없는 기존 회사를 채운다(계정이 있는 회사는 건드리지 않는다). 000025 는 2자리 계정(11·21·41 …)을 1자리 분류(1 자산 … 5 비용) 아래로 잇도록 함수를 고치고 기존 계정을 보정한다(계정 트리 루트 5개).
  5. `$C up -d api web`
- 업데이트: `git pull` → `KERP_IMAGE_TAG` 갱신 → `$C build api web` → `$C run ... /app/migrate up` → `$C up -d api web`.
- 내리기: `$C down` (`-v` 금지 — DB 볼륨이 지워진다).
- 관리자 계정 자격증명은 서버의 `ADMIN_CRED`(600) 에만 있다. git·docker 빌드 컨텍스트 모두 제외되어 있다.
